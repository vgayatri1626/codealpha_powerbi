Task 3 Completed: Real Estate Market Trends Dashboard!

I'm excited to share my third project for the CodeAlpha internship — 
an interactive Real Estate Market Trends Dashboard built with Power BI.

📊 What this dashboard does:

· Tracks 30,000+ property records including prices, rents, and demand scores
· Visualizes Average Property Price and Rental Yield by City
· Analyzes market demand share across different locations
· Shows supply conditions using Days on Market data
· Includes Crime Rate vs Property Price analysis for deeper insights
· Interactive City slicer for real-time filtering

🛠️ Tools Used:

· Power BI Desktop
· DAX for calculating Rental Yield
· Power Query for data preparation
· PPIA Real Estate Dataset (Kaggle)

💡 Key Insight: The dashboard helps easily identify high-demand cities 
and compares rental yields across markets — making property analysis faster 
and data-driven.
