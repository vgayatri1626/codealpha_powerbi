# 📊 NovaTech Financial Health Dashboard

## 📌 Overview

This project is part of **Task 1 of my CodeAlpha Internship**.

I created an interactive **Financial Health Dashboard** using **Microsoft Power BI** to analyze NovaTech's financial performance and provide a clear overview of its revenue, profit, expenses, and overall financial health.

## 🎯 Objectives

- Analyze total revenue and net profit
- Compare revenue and profit trends
- Understand the company's expense distribution
- Compare budgeted revenue with actual revenue
- Analyze gross profit and net profit
- Present a balance sheet summary
- Build an interactive and easy-to-understand dashboard

## 📈 Dashboard Highlights

The dashboard includes:

- 💰 **Total Revenue**
- 📊 **Total Net Profit**
- 📈 **Average Profit**
- 💸 **Total Expenses**
- 📉 **Revenue vs Net Profit Trend**
- 📊 **Gross Profit vs Net Profit Trend**
- 🍩 **Expense Breakdown**
- 📊 **Budget vs Actual Revenue**
- 📋 **Balance Sheet Summary**
