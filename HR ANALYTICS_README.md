# HR Analytics Dashboard — Workforce Insights


## 📌 Project Overview
This project is an **HR Analytics Dashboard** built for the **CodeAlpha internship** using **Power BI**. It provides actionable insights into workforce management, employee attrition, satisfaction, and performance.

## 🎯 Objective
To create a dashboard that helps HR teams:
- Track recruitment metrics and employee turnover
- Analyze employee satisfaction and performance
- Forecast hiring needs using predictive analytics

## 📊 Dashboard Features
Feature  
**KPI Cards** 
    Total Employees, Active Staff, Attrition Rate, Avg Satisfaction |
**Attrition Analysis** 
     Attrition by Department, Active vs Separated |
**Satisfaction & Performance**
     Satisfaction by Department, Satisfaction vs Performance |
**Tenure Analysis** 
      Employees by Years at Company |
**Predictive Analytics** 
      Projected Hiring Need based on attrition |
**Interactivity** 
      Department slicer for real-time filtering |

## 🛠️ Tools Used
- **Power BI Desktop** — Dashboard creation and visualization
- **DAX** — Calculated measures (Attrition Rate, Projected Hiring Need)
- **Power Query** — Data cleaning and transformation
- **Kaggle** — IBM HR Analytics Dataset

## 🔍 Key Insights
- **Total Employees:** 1.47K
- **Attrition Rate:** 16%
- **Projected Hiring Need:** 237 new hires next year
- **Highest Attrition:** Sales Department
- **Lowest Satisfaction:** Research & Development
